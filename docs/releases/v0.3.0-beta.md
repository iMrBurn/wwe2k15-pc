## WWE 2K15 PC 0.3.0 beta

**The native renderer is now the default.** It is much lighter on weak PCs and integrated graphics (AMD integrated GPU: 60 fps from 480p to 1080p, 6-man Elimination Chamber included, where the normal renderer reached 9-32 fps), and it runs at 60 fps on 2 CPU cores. The normal renderer is still there (untick GRAPHICS > "Rendu natif") and the launcher falls back to it automatically if the native one cannot start. **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Changed
- **"Rendu natif" is ticked by default.** On the first start of this version the launcher also turns it on for installs that had it unticked by an older launcher, and shows a note once. After that your choice is respected: if something goes wrong, untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- The first launch with the native renderer prepares the game's shaders (a few seconds, up to about 10 s on a weak PC).

### Fixed
- **White attires (native renderer, AMD integrated GPU)** (#27): the copy of a freshly composed attire back to the game's memory stopped after 6 passes in a row, so the last parts of the attire were never copied. The limit is now 32 and a final copy is made when the texture rests. *Please retest DLC / SummerSlam attires and Superstar Threads and tell us the result.*
- **Crash about 20 s after start on an Intel PC, "Invalid UTF-8"** (#24): a content name read from the game's memory could contain invalid bytes and the exception closed the game. Names are now cleaned, and an exception in that step only fails the call. If it happens again the log names the cause.
- (Already in 0.2.6) White DLC wrestler models with the normal renderer, dark characters in pin close-ups, the keyboard as player 2 (use it with a controller connected and press START on the controller), automatic fallback to the normal renderer, native 360p / 480p.

### Reminder
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Intel: waiting for player confirmation on the native renderer; with the normal renderer the first launch can freeze up to ~20 s (use the native one).
- Create a Moveset can get stuck on a loading screen for some players (#25, being looked at).
- Loading screens take about 10-13 s for the biggest matches (no fix found yet).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
