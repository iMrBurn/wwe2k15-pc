## WWE 2K15 PC 0.3.4 beta

**Steam Deck and Linux (Proton) groundwork, controller navigation in the launcher.** **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept. *Nothing changes for normal Windows PCs apart from the small items below.*

### New
- **Steam Deck / Linux (Proton)**: the launcher detects a Steam Deck and, on a first run only, picks the native renderer, 720p internal resolution, fullscreen and vsync. Your own settings are never changed. Under Wine the launcher window is placed and sized correctly, fonts have fallbacks, and the update check no longer fails on proxy settings. If the shader compiler (`dxcompiler.dll`) cannot be used, the native renderer now stops with a clear message and the launcher switches to the normal renderer by itself (before, the window stayed black). Guide: `docs/LINUX_STEAM_DECK.md`. *We cannot test on a real Deck: reports are very welcome.*
- **Controller navigation in the launcher**: the left stick moves the focus, the focused tile has a gold outline, A / Enter / Space activate it, and PLAY is selected by default. On the Steam Deck use a *Gamepad* Steam Input layout for the shortcut, not the Desktop one.
- **Loading diagnostics**: the `[load]` lines of the log now show how much the game reads from disk and the CPU time used, so a slow loading can be traced to a hard disk or a slow CPU in bug reports.

### Reminder
- 0.3.3 (previous version): fixes a crash just before a match starts on PCs with few CPU cores (#24) and slow-motion entrances on slower PCs (the game goes back to its original 30 fps for scenes it cannot run at 60 fps).
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Multi-man matches (6-man, fatal four) can stutter on slow CPUs (#27, #28); we measured that skipping shadows or crowd draws does not help a slow CPU. A log from such a match helps (`logs\wwe2k15_*.log`).
- Loading screens take about 10-13 s for the biggest matches (the game itself waits; no safe fix found).
- Showcase: a crash after a cutscene in a casket match was reported (#24); logs welcome. Create a Moveset can get stuck on a loading screen for some players (#25).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
