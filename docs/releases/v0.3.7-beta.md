## WWE 2K15 PC 0.3.7 beta

**An EXIT entry in the main menu.** **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### New
- **EXIT in the main menu**: the dead "SHOP" entry (it only showed a network error) now reads **EXIT** (EXIT, QUITTER, SALIR, ESCI, BEENDEN) and asks "Quit the game?" with Yes / No. The box starts on **No**: Enter / A / Esc / B cancel, Left then Enter / A quits, the mouse works too. "Xbox Live" is unchanged. To switch it off: F10 > "Main menu EXIT entry" (needs a restart) or `wwe2k15_quit_entry = false` in `wwe2k15.toml`. *Tested with keyboard and mouse; please tell us if it works with your controller.*

### Reminder
- 0.3.6: in-game settings menu (**F10**, or hold **Back + Start** on a controller) with a "Quit game" button, and experimental options (camera cuts on finishers/grapples, logo import keeping proportions, Universe "free shows", use a COPY of your save).
- 0.3.5: portraits of created superstars and thumbnails of created arenas are saved clean (open and save again the ones created before), and a fix for the freeze in Create a Championship.
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Limit on how much a logo can be stretched in Create an Arena (#36): looked at, not found yet.
- Multi-man matches can stutter on slow CPUs (#27, #28). Loading screens take about 10-13 s for the biggest matches (the game itself waits). Showcase: a crash after a cutscene in a casket match and sound cutting out in videos on a 2-core CPU were reported (#24); a crash in the render thread (#39) is being looked at.
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
