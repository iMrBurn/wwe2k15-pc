## WWE 2K15 PC 0.2.6 beta

Fixes for white wrestler models with the **normal** renderer, dark characters in pin close-ups (native renderer), a safer native renderer (automatic fallback), and a keyboard-as-player-2 fix. **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **White / blank DLC wrestler models, normal renderer** (#10, #12, #15, #17, #20): the textures that build a wrestler's skin, attire and damage were skipped while their shaders were still being prepared and were never redone. They now build their shader at once. *Please retest DLC wrestlers, 2K Showcase and Superstar Threads (normal renderer, first launch).* If you see stutters while loading, tell us.
- **Dark characters in pin / grapple close-ups, native renderer** (#14, #16): a partial screen clear was applied to the whole picture. Partial clears now stay partial. *Please check a pin and tell us.*
- **Keyboard as separate player:** when the keyboard validated the title screen it became a guest without a profile, so the game said "not signed in" and nothing was saved. The option is now used only when a controller is connected, and a note explains to press START on the controller.

### New
- **Automatic fallback:** if the native renderer cannot start on a PC, the launcher starts the normal renderer for you, unticks "Rendu natif" and shows a note.
- Native renderer resolutions **360p and 480p** (plus AUTO, 540p ... 4K).
- Shader conversion and pipeline building run on low-priority background threads, so they steal less time from the game.

### Measured here (RTX and AMD integrated GPU)
- AMD integrated GPU, native renderer: **60 fps from 480p to 1080p**, including a 6-man Elimination Chamber; the normal renderer only reaches 9-32 fps there. Weak PC: use the native renderer.
- Native renderer on 2 CPU cores: 60 fps, same CPU cost as the normal renderer.

### Reminder
- Weak PC or integrated graphics: tick GRAPHICS > "Rendu natif (expérimental)".
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Intel: the native renderer crash was fixed in 0.2.4, waiting for confirmation; with the normal renderer the first launch can freeze up to ~20 s.
- Create a Moveset can get stuck on a loading screen for some players (#25, being looked at).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
