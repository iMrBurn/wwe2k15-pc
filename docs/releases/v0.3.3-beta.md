## WWE 2K15 PC 0.3.3 beta

**Crash fix for PCs with few CPU cores, and slow PCs no longer slow down the entrances.** **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **Crash just before a match starts** (seen on an Intel HD 520 with 2 cores, #24): the game could signal a system event on memory that had been reused for something else, and the engine used it without checking. It now checks the object type and re-creates it if needed. It is a timing problem, so it showed mostly on PCs with few cores. *Please confirm on your PC if you had random crashes at the start of a match.*
- **Entrances and victory scenes in slow motion on slower PCs** (#28, GTX 940MX): the 60 fps entrances need more CPU time per frame. If the PC cannot hold 60 fps during a scene, the game now goes back to its original 30 fps by itself for the rest of the session (the scene keeps its normal speed and length). Nothing to do; `[fps] scene cannot hold 60 fps` appears in the log. To turn this off, set `wwe2k15_60fps_auto = false` in `wwe2k15.toml`.

### Reminder
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).
- The first match after a new install is slower on weak GPUs (the game prepares its graphics once); the next launches reuse them.

### Known issues
- Multi-man matches (6-man, fatal four) can stutter on slow CPUs (#27, #28); we have no fix yet. A log from such a match helps (`logs\wwe2k15_*.log`).
- Create a Moveset can get stuck on a loading screen for some players (#25, being looked at).
- Loading screens take about 10-13 s for the biggest matches (no fix found yet).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
