## WWE 2K15 PC 0.1.4 beta

Update of the unofficial PC port of WWE 2K15. **No game data is included.** If you already have 0.1.x, the launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### AMD graphics cards
- **Much faster matches on AMD GPUs** (reports #3 and #4): the precise rendering mode (FSI) is 3-4 times slower than the other one on AMD cards. The game now picks the right mode by itself ("auto": FSI on NVIDIA/Intel, the lighter mode on AMD). The startup log says which one is used.
- If you set "accurate rendering (FSI)" yourself in GRAPHICS, nothing else changes for you: untick it for the lighter mode on any card.

### Loading and stutter
- The graphics driver's pipeline cache is now saved between runs, so the first matches after a restart should hitch less (mostly on older drivers; not yet measured on one, feedback welcome).
- A bit less CPU work in the graphics-command thread (descriptor reuse, fewer register writes).

### For bug reports
- The log now has a "GPU time" line every 5 seconds: if you are under 60 fps and "busy" is close to 100 %, the graphics card is the limit; if it is low, the processor is. Please attach `logs\wwe2k15_*.log` to issues.

### Known issues
- Integrated GPUs (for example Vega 7) stay GPU-bound in matches (about 15-35 fps). For them: PERFORMANCE preset, 720p.
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log`.
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
