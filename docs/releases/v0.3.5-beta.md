## WWE 2K15 PC 0.3.5 beta

**Fixes for created content (superstar portraits, arena thumbnails) and for a freeze in Create a Championship.** **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **Created superstars: portrait shown as noise on the select screen** (#34). The portrait is drawn once, in 4 stacked pieces, when you save the wrestler; the native renderer only kept the top piece (the head). It is now saved complete.
- **Custom arena thumbnail full of artefacts in SELECT ARENA** (#35). The picture the game takes when you save the arena is now read back at once.
- **Freeze in Create a Championship when moving or resizing logos** (#33). Two threads of the game wrote into the same graphics command queue without any lock, and a command could be cut in the middle (the game then waited forever). The game now makes them take turns. It is on by default; to turn it off, set `wwe2k15_d3d_ring_lock = false` in `wwe2k15.toml`. The same race existed in the normal renderer, which is covered too. *This may also help with some freezes in other creation modes (#29): please tell us.*

**Important: superstars and arenas you created before this version keep their broken picture. Open them, change nothing and save again (ACCEPT) once to get a clean portrait / thumbnail.**

### Reminder
- 0.3.4: Steam Deck / Linux (Proton) groundwork, controller navigation in the launcher, custom logo import (launcher MODS tab, experimental), loading diagnostics. 0.3.3: fix for a crash before a match on PCs with few CPU cores and for slow-motion entrances on slower PCs.
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Multi-man matches (6-man, fatal four) can stutter on slow CPUs (#27, #28); a log from such a match helps (`logs\wwe2k15_*.log`).
- Loading screens take about 10-13 s for the biggest matches (the game itself waits; no safe fix found). The first seconds after launch can pause for 1-8 s before the title.
- Showcase: a crash after a cutscene in a casket match, and sound cutting out in the video packages on a 2-core CPU, were reported (#24). Create a Moveset can get stuck on a loading screen for some players (#25).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
