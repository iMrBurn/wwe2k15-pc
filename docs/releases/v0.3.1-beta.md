## WWE 2K15 PC 0.3.1 beta

Fixes the **white attires** that some players still had on the native renderer with weak or integrated GPUs (#27, and probably the older white-model reports #10, #12, #15, #17). **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **White attires (native renderer, integrated GPUs at 720p)**: the game builds Superstar Threads / edited attires in a 2048x1024 picture while a smaller 1280x720 depth buffer was still attached; the graphics API cuts the picture to the smallest attachment, so only its top-left 1280x720 part was drawn and the rest stayed white. This only showed on GPUs rendering at 720p (Radeon 610M, Intel...); a strong GPU rendering at 1440p was not affected. The smaller depth buffer is now left out for that pass. *Please retest the same match (delete the "cache" folder once) and tell us the result.*
- Texture copies back to the game's memory are now properly synchronised (a correctness fix).

### Reminder
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- Intel: waiting for player confirmation on the native renderer; with the normal renderer the first launch can freeze up to ~20 s (use the native one).
- Create a Moveset can get stuck on a loading screen for some players (#25, being looked at).
- Loading screens take about 10-13 s for the biggest matches (no fix found yet).
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
