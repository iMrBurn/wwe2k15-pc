## WWE 2K15 PC 0.4.0 beta

**Fixes for accented and special characters in paths (game cannot save or install DLC), a launcher that no longer freezes, an automatic low-resolution profile for weak PCs, and an EXIT entry in the main menu.** **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **Accents in the Windows user name or folders** (#40, for example a user called "Hernán"): the game could not write its data folder ("Access is denied"), so none of the DLC were installed and creating the save data froze the game. The game now reads its paths as UTF-8 and the launcher passes safe short paths. Paths with Japanese or other non-Latin characters used to crash the game at start: fixed too. *If you were blocked by this, please update and tell us.*
- **The launcher froze while installing the Title Update or a DLC** (each is a few hundred MB): the install now runs in the background with a progress line.
- If Windows (antivirus, "Controlled folder access") refuses writing to the game's data folder, the launcher tells you with a red note and a button that uses a `user_data` folder next to the launcher instead. A gold note warns when a folder name has special characters.

### New
- **EXIT in the main menu**: the dead "SHOP" entry (it only showed a network error) now reads **EXIT** (QUITTER, SALIR, ESCI, BEENDEN) and asks "Quit the game?" Yes / No. The box starts on **No**: Enter / A / Esc / B cancel, Left then Enter / A quits; the mouse works too. Turn it off in F10 > "Main menu EXIT entry" or `wwe2k15_quit_entry = false` in `wwe2k15.toml`. *Tested with keyboard and mouse; tell us if it works with your controller.*
- **Weak PC profile** (#41): on a PC with an integrated GPU and 4 or fewer processor threads the native renderer now picks 540p automatically (480p with 2 threads) instead of 720p, and the launcher shows a note once. It never applies when you choose a resolution yourself; turn it off with `svr_auto_lowend = false`. Note: with a 2-core CPU of an older generation the game cannot reach 60 fps even at low resolution; 30 to 45 fps is a realistic target.
- Since 0.3.6: in-game settings menu (**F10**, or hold **Back + Start**), with a Quit button and experimental options (logo import keeping proportions, Universe "free shows": use a COPY of your save).

### Reminder
- 0.3.5: portraits of created superstars and thumbnails of created arenas are saved clean (open and save again the ones created before).
- The native renderer is the default since 0.3.0: untick GRAPHICS > "Rendu natif" to return to the normal renderer.
- You need Title Update 4 (`tu00000004_00000000`). With no controller, the launcher turns the keyboard on (Space = A, Enter = Start).

### Known issues
- **Create a Championship can still freeze** when you move or resize logos or reliefs on some PCs (#33): the 0.3.5 protection reduces it but does not remove it; we can reproduce it now and are working on it.
- Limit on how much a logo can be stretched in Create an Arena (#36): not found yet.
- Multi-man matches can stutter on slow CPUs (#27, #28). Loading screens take about 10-13 s for the biggest matches (the game itself waits). Showcase: a crash after a cutscene in a casket match and sound cutting out in videos on a 2-core CPU were reported (#24); a crash in the render thread (#39) is being looked at.
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log` (and `crash_*.txt`).
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
