## WWE 2K15 PC 0.2.1 beta

Fixes for the first reports on the native renderer. **No game data is included.** The launcher offers this update by itself (ABOUT page): your game folder, mods, settings and saves are kept.

### Fixed
- **Native renderer brightness** (#7): the game's Brightness option is now applied, and the crowd is no longer too bright (the known issue of 0.2.0).
- **Replay file** (#9): the game could not create its replay file (it wants ~150 MB of free cache space and the port reported much less). The in-match instant replay now plays.
- **Crash after a Money in the Bank match in Universe mode** (#11): a guard skips the faulty call instead of crashing. If the log says `crash guard: sub_8253D490 skipped`, please tell us.
- **White / glitched wrestler models on AMD** (#10, #12): a possible fix (reflection textures were read before being resolved). Could not be reproduced here: **please retest and tell us** (Superstar Threads, 2K Showcase, Randy Orton '11).
- **Crash reports** now start with the crashing thread's stack, and the native GPU line in the log shows the driver version and VRAM. This helps us with the Intel (#8) and GeForce 940MX (#6) driver crashes: if the game crashes, please attach the new `crash_*.txt` and `logs\wwe2k15_*.log`.

### Known issues
- Native renderer: tested on NVIDIA and one AMD integrated GPU only; AMD desktop cards report it works well (RX 6750 XT), Intel is still being looked at.
- Online features (Xbox Live, Xbox Store) do not work. No native Linux build: use Proton.

Bugs: please open an issue with your GPU, CPU, the scene and `logs\wwe2k15_*.log`.
Never share the game files, the Title Update or DLC. Not affiliated with WWE, 2K or Yuke's.
